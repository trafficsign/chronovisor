Chronovisor Neural Graph Viewer

done 2026-07-29 chronovisor-neural-graph-viewer

概要

Chronovisor Wiki の知識グラフを 3D force-directed graph で可視化するビューア。 AIがMCP経由でページを読み込んだ際に、ニューロンが発火するようなアニメーション効果を表示する。

要件

コア機能

  • 3D Force-Directed Graph: FableモックアップのCanvas 3D投影・発火エンジンで Wiki ページをノード、wikilink をエッジとして描画
  • ニューロン発火エフェクト: AIが chronovisor_read / chronovisor_search でページにアクセスした時にノードが発光し、リンク先に伝播
  • CADライクなナビゲーション: ポインタドラッグ・ホイール・ズームボタンによるズーム、回転、フォーカス
  • カテゴリフィルタ: 左サイドバーの Explorer でカテゴリ別にフィルタ
  • ノードクリック: ノードをクリックするとカメラが寄って詳細情報を表示

UI レイアウト

  • Obsidian のサイドバー切り替え風のビュー構成（ファイル一覧 / グラフビュー）
  • 左サイドバー: カテゴリ別ファイルツリー（Explorer）
  • 中央: 3D グラフビューポート
  • 右サイドバー: コントロール、STIMULATE ボタン、ノード詳細
  • ノードクリック → ツリーの該当ファイルへ自動スクロール＆ハイライト
  • ツリーのダブルクリック → ページのプレビュー表示

デザイン

  • 既存ダッシュボード（Observatory）のデザインシステムに準拠
  • precision-minimal dark テーマ（Linear/Vercel 系譜）
  • Geist Sans / Geist Mono フォント
  • カラートークン: --bg: #08090a, --accent: #828fff, --green: #3dd68c, --amber: #e8b04b, --red: #ff6166

レイアウトモード

  • ORGANIC: 自然な force-directed レイアウト（デフォルト）
  • CLUSTERS: カテゴリ別にクラスタリングしたレイアウト

リアルタイム連携

  • WebSocket で MCP イベント（chronovisor_read, chronovisor_search, chronovisor_record）を受信
  • アクセスされたページのノードが発火 → リンク先に伝播
  • 発火色: RECALL=アクセント青, SAVE=グリーン, INGEST=アンバー

データ構造

  • ノード: ~/.chronovisor/pages/ 配下の各 .md ファイル（3,266ページ、80カテゴリ）
  • エッジ: Markdown 内の wikilink ([[page-name]]) を解析して生成（13,001リンク）
  • フロントマター: YAML の title, updated, tags, raw_keywords
  • 実データAPI: ops/cortex.py がローカルWikiから動的生成し、/api/cortex/graph で配信。ページ本文と固定JSONはGitへ格納しない

リファレンス

技術選定

レンダリングFable Canvas 2D + 3D投影（外部依存なし）
カメラ制御Fableモックアップ準拠の独自orbit / zoom / focus
リアルタイムWebSocket + durable telemetry tail
フォントSF Mono / system UI（Fableモックアップ準拠）
バンドル追加vendorなし。HTML / CSS / JavaScriptを同梱
